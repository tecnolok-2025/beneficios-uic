# Parche v3.9.2 → v3.9.3

Aplicar únicamente sobre una instalación v3.9.2.

Incluye cambios de frontend, servidor, esquema Neon, configuración y pruebas para: registro/recuperación de empresas, prueba con código de 6 dígitos, vista administrador como empresa, imágenes embebidas, deduplicación, baja de destinatarios y control administrativo del modo masivo.

La migración de base es aditiva y no borra beneficios, flyers ni destinatarios existentes.

Después de desplegar, mantener el modo masivo apagado durante el piloto y comprobar primero la configuración SMTP con `tesoreria@uic-campana.com.ar`.
