# Parche Beneficios UIC v4.0.0 → v4.0.1

Este parche reúne la corrección general del Monitor y el acceso directo para validación.

Cambios principales:
- Monitor general permanente para Administración.
- Monitor de envíos para beneficiarios con permisos separados.
- Acceso al Monitor luego de aprobar una campaña.
- Correo de Tesorería con botones “Ver beneficio en el Portal” y “Abrir Validación UIC”.
- En Validaciones, botón “Ver beneficio publicado”.
- El enlace administrativo abre directamente Validaciones y focaliza la campaña; si no hay sesión, solicita la clave primero.
- No requiere migración de Neon ni modifica padrón, campañas existentes o beneficios.

Aplicación: copiar estos archivos sobre la instalación v4.0.0 conservando la misma estructura y desplegar nuevamente en Render.
